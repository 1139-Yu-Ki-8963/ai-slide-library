# 携帯レビューURL提示チェックリスト

## 配信前

- [ ] レビュー成果物専用ディレクトリをドキュメントルートにする
- [ ] リポジトリ全体や公開サイトを配信しない
- [ ] ユーザー指定のプライベートIPに限定してbindする（`0.0.0.0`禁止）
- [ ] セッション終了後もサーバーが維持される方式で起動する

## URL検証

- [ ] 対象1枚につき独立HTMLを1つ作る
- [ ] 各HTMLが「現在版1枚→改善提案1枚」を表示する
- [ ] 各HTMLに適用規約、指摘、変更点、保持情報、未承認情報を含める
- [ ] 提示直前に対象IP・ポートへ `curl` し、各HTMLがHTTP 200である
- [ ] 各画像リクエストがHTTP 200である
- [ ] 各HTMLの画像数が2枚である
- [ ] 390px幅で横スクロールがない
- [ ] 実機未確認の場合は「Mac上のモバイル幅エミュレーションとLAN側HTTP確認」と明記する

## 提示禁止条件

- サーバーが停止している
- HTTP 200を提示直前に確認していない
- 1枚に全件を縮小表示している
- 公開URL、GitHub Pages、外部ホスティング、トンネルを使っている
- プライベートIPをHTML、リポジトリ、カタログ、コミットへ書き込んでいる
