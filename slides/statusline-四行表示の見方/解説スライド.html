Claude Code — statusline

statuslineは入力欄の下に、状態を4行で常時表示する

モデル・セッション・リソース消費・フロー進捗の4行構成（statusLine.command で指定）

1Opus 4.6 (1M context) | 📂 my-project | Branch: feature/add-dashboard | アカウント: my-account
2Session: a1b2c3d4 | Name: 機能実装セッション
3◔ ctx:23% ◑ 5h:58% ◕ 7d:84%
4Phase 3 実装 ▰▰▰▰▰▱▱▱▱▱▱▱▱ 5/12 API endpoint 追加
行 1

モデル・作業場所

  • モデル名使用中のClaudeモデル（Opus 4.6 / Sonnet 5 等）
  • フォルダ / Branch作業ディレクトリと現在のGitブランチ
  • アカウント接続先の識別名（.claude-xxx → xxx）
行 2

セッション情報

  • SessionセッションIDの先頭8文字
  • Name/name で付けた名前（未設定なら非表示）
行 3

リソース使用率

  • ctxコンテキスト使用率 — 会話が長くなると上昇
  • 5h / 7d5時間・7日間のレートリミット消費率
記号は残量の目安：○ 0–12%　◔ 13–37%　◑ 38–62%　◕ 63–87%　● 88%以上
<50% 50–79% ≥80% 取得不能
行 4

開発フロー進捗

  • Phase N・バー現在のフェーズ名と達成度
  • N/M・ステップ名現在ステップ / 総数と、進行中の作業名
flow-status.json がある場合のみ表示される条件付き行
使いどころ 見るべきは行3 — 5h / 7d の消費率が、Cursorへ退避するかの判断材料になる 1 / 1
