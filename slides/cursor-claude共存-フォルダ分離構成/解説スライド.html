REPOSITORY STRUCTURE — DUAL AI

CursorとClaude Codeの専用設定を分離する

.cursor/と.claude/を主配置にし、ルート文書の読込対象も製品ごとに確認する

専用設定は .cursor/ と .claude/ に分け、共有指示の重複と競合を防ぐ
専用設定とルート文書
<repo>/
├─ .claude/ Claude Code 専用
│  ├─ rules/
│  │  ├─ always/ 常時注入
│  │  └─ scoped/ 条件注入
│  └─ skills/<name>/SKILL.md 手順の入口
├─ .cursor/ Cursor 専用
│  ├─ rules/*.mdc ファイル条件で適用
│  └─ skills/<name>/SKILL.md 互換して発見
├─ AGENTS.mdCursor 自動読込
└─ CLAUDE.mdClaude Code・Cursor CLI が読込
1

Claude Code の設定領域

CLAUDE.md と .claude/rules/ を用途に応じて読む。Skill は .claude/skills/<name>/SKILL.md に置き、専用設定と共有指示を区別する。

対象: CLAUDE.md / .claude/rules/{always,scoped}/ / .claude/skills/<name>/SKILL.md

2

Cursor の設定領域

.cursor/rules/ は設定に応じて適用される。Cursor CLI は AGENTS.md と CLAUDE.md もルートで読み得るため、共有指示の重なりを確認する。

対象: AGENTS.md / CLAUDE.md / .cursor/rules/*.mdc / .cursor/skills/<name>/SKILL.md

REPOSITORY STRUCTURE — SHARED PORTAL

共有資料はproject-portalに集約する

両AIが同じ設計情報を参照できるよう、共有資産と各製品の参照経路を分けて管理する

専用設定は分離し、設計書・規約・可視化は人とAIの共通参照点へ集約する
<repo>/project-portal/両 AI が参照
├─ 基盤情報/ 技術スタック・用語辞書
├─ 規約/ コーディング規約・命名規約
├─ 一覧・設計図/ 画面・API・テーブル等 9 種
├─ 交差ビュー/ 権限マトリクス・CRUD 図
└─ 解析概要/ 調査結果と全体像

project-portal/ — 共有資産の主役

設計情報と技術資産を一元管理するHTMLサイト。規約・一覧・交差ビュー・解析概要を集約し、人もAIもブラウザで同じ情報を参照する。

Claude CodeCLAUDE.md と .claude/ の指示から、必要な共有資料への参照経路を明示する。
CursorAGENTS.md・CLAUDE.md・.cursor/ の適用関係を確認し、同じ共有資料へ到達させる。

対象: project-portal/ 配下の基盤情報・規約・一覧・設計図・交差ビュー・解析概要
