# 検査記録: ai開発課題-課題比較影響型

## 今回の主題レビュー

| 観点 | 結果 | 備考 |
|---|---|---|
| 主題の明示 | PASS | AI開発で優先すべき2つの課題を左右の同じ構造で比較している |
| 比較軸の対称性 | PASS | 両課題とも「現状の課題データ」と「業務に生ずる影響」を同じ順序で表示している |
| 数値と説明の対応 | PASS | 左は時間、右はレビュー観点・母数・運用の指標として、各数値の意味を直下で説明している |
| 1280×720収まり | PASS | 左右パネル、フッターとも画面内に収まり、文字切れなし |
| サムネイル判読 | PASS | 2つの課題名と左右の対比構造を縮小表示でも確認できる |

## スライド固有の主題

- AI開発で優先すべき課題は「前提を探す時間」と「成果物の品質ばらつき」の2つである。
- 2つの課題を同じ指標・影響構造で並べ、個別対策ではなく共通原因への対処が必要だと伝える。
