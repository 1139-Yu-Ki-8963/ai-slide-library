CLAUDE CODE

Claude Code｜docs配置ガイド

CLAUDE.mdを入口に、規約・手順・専門エージェント・実行設定を役割別に分離する

書く内容置く場所AIへの効果
プロジェクト文脈 CLAUDE.md目的・構成・実行コマンド・参照先 最初に読む入口を固定する
パス別ルール .claude/rules/*.md対象パスごとの制約と判断基準 関係する作業だけへ規約を適用する
再利用する手順 .claude/skills/<name>/SKILL.md繰り返す作業の入力・手順・完了条件 担当者が変わっても同じ流れで実行する
専門エージェント .claude/agents/*.md役割・利用ツール・返却形式 調査・実装・レビューの責務を分ける
実行・接続設定 .claude/settings.json外部接続は .mcp.json 許可範囲と接続先をコードから分離する
PROJECT TREE

Claude Code用の配置像

project/
├── CLAUDE.md
├── docs/
│   ├── architecture.md
│   └── operations.md
├── .claude/
│   ├── rules/
│   │   └── testing.md
│   ├── skills/
│   │   └── release/
│   │       └── SKILL.md
│   ├── agents/
│   │   └── reviewer.md
│   └── settings.json
├── .mcp.json
└── src/

配置の原則：CLAUDE.mdは入口に絞り、詳細はdocsへ、強制ルールと実行手順は専用ディレクトリへ分ける。
