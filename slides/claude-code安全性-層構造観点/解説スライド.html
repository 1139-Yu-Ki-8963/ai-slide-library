Claude Code — 安全性の仕組み

Claude Codeは2層で安全性を確保する

Permissionがツール呼び出しを制御し、SandboxがBashのシステムアクセスをOSレベルで制限する

第1層｜ツール制御

Permission

全ツール呼び出しが対象

Claudeのツール呼び出しを allow / ask / deny の3段階で制御する

Read・Write・Edit・Bash等の各ツールに、自動許可（allow）／都度確認（ask）／禁止（deny）を settings.json で設定する。denyは他の設定で上書きできない最強の制限。

Read → allow（自動許可） Write → ask（都度確認） Bash(rm -rf *) → deny（禁止）
↓

Permissionを通過したBashコマンドに、さらにSandboxが適用される

第2層｜OS制限

Sandbox

Bashコマンドが対象

ファイル書き込みとネットワーク接続をOSレベルで制限する

書き込み可能なディレクトリをホワイトリストで限定し、接続先を許可ドメインに制限する。アプリケーション層ではなく、OSのセキュリティ機構で強制する。

書込先をプロジェクト内に限定 接続先ドメインを許可制に 認証情報ファイルの読取を遮断

OS実装: macOS → Seatbelt ／ Linux → bubblewrap（2026年7月時点の公式仕様）

層の意味 アプリの設定（Permission）をすり抜けても、OS（Sandbox）が最後に止める — 二重で守る 1 / 1
