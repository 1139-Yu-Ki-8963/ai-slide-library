## タスク限定の観点（次回の再検査項目）

| 観点 | 検査内容 |
|---|---|
| 呼び名-正本一致 | フォルダ名・成果物名・文書名が `docs/design/common/作業ディレクトリと出力の配置.md` と一致しているか。2026-09-09 に `facts/`・「要件定義5文書」・「アーキテクチャ調査書」の3件がずれていた実例がある |
| 呼び名-台帳まで一致 | HTML だけでなく `docs/スライド蓄積簿.md`・`docs/スライド主題一覧.md` も直したか。カタログの説明文はこの2つから生成される |
| 呼び名-1枚内統一 | 同じ対象に2つ以上の呼び名が1枚の中で混在していないか。kicker・title・「このツール」のような指示語も対象に含める |
| ツリー-中身行一致 | 各カードのツリーの項目と、同じカードの「中身：」行が食い違っていないか |
| ページ間-種別数一致 | 1枚目のカードのツリーの直下の項目数と、2枚目の見出しが言う種別数が一致しているか |
| 横並び列挙-残存 | フォルダを横に並べた列挙が残っていないか。3ページすべてを見る |
| ツリー-横幅収まり | カード内・右側の両方のツリーの最長行が枠に収まっているか。右側の `.treebox pre` は overflow の指定を持たないため、はみ出しがそのまま出る |
| 断言-範囲 | 「〜も〜も作業フォルダに出す」のような全称の断言が、正本の例外（`ai-work/records/` に残る完了記録）と矛盾していないか |
