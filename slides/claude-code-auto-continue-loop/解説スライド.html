Claude Code 公式機能

Auto-continue — 解除後に中断ターンを自分で再試行する

切り替えは /config の Continue automatically at usage limit。off で止まる

セッション
この時刻に到達 リミット
この時刻に解除 再開
実行中 通常どおり進む
待機 新規リクエストが block される
再開後 中断したターンを自動で再試行する 人が打ち直さない
設定 /config の「Continue automatically at usage limit」。デスクトップ版は制限画面の「Auto-continue when limits reset」 発火の条件 Claude Code が起動して待機している間だけ発火する。ターミナルを閉じると止まる 続ける手段 セッションをバックグラウンド化すれば、ターミナルなしで動き続ける
Claude Code 公式機能

/loop — loop.md に書いた手順を、尽きるまで回す

間隔とプロンプトはどちらも省ける。省くと .claude/loop.md を反復ごとに読む

.claude/loop.md

TASK.md の未完了タスクを上から1件だけ処理する。

完了したらそのタスクの行を TASK.md から消す。

未完了タスクが残っていなければ、ループを止める。

↑　残りがあれば、次の反復で先頭へ戻る
読む loop.md の指示を読む
1件処理 先頭のタスクを片づける
行を消す 済んだ行を一覧から削る
残りを見る 未完了があるか確かめる
残りが無ければ、そこで止まる
呼び方 /loop 5m <指示> は固定間隔。/loop <指示> は間隔をモデルが1分から1時間で選ぶ。/loop だけなら loop.md を読む 止め方 次の反復を待っている間に Esc。間隔の指定によらず7日で失効する 一覧の名前 参照する側と合っていれば何でもよい。TASK.md という名前に公式の定めはない
