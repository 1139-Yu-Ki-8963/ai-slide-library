global × always

global × scoped

対象パスの操作時だけ注入する共通規約。コード・開発フロー・hook設定などを置く。

プロジェクト固有<repo>/.claude/rules/リポジトリ単位の規約と値の追加

project × always

そのリポジトリ内で常時必要な文脈と、globalから委譲された値を置く。

project × scoped

そのリポジトリ固有の条件付き規約。マージ時・コード編集時・レビュー時などに絞る。

分類の原則 所有レベルで分けてから、注入タイミングで分ける — 二軸を1つの階層に混ぜない 1 / 3
Claude Code 設定管理 — グローバル規約

グローバル規約は共通原則と対象別基準を分ける

alwaysは全セッション、scopedは対象パス操作時だけ読み込む

グローバル~/agent-home/rules/全プロジェクト共通の規約
always/全セッションで常時注入
├─naming/commit-branch/命名規約（hook 同居）
├─review-checklist/text-dictionary/語彙辞書
├─agent/subagent-selection/委任規約（hook 同居）
└─response/応答規約の代表例

置くもの：どのプロジェクトでも常に守る原則。命名・語彙・委任・応答の基本規約を置く。hookと同居する規約は自動検証と対になる。

scoped/対象パス操作時のみ注入
├─review-checklist/code/paths: **/*.ts
├─dev-flow/gate/paths: src/**
└─agent-config/hooks/paths: tools/hooks/**

置くもの：対象パスに触るときだけ読ませる対象別基準。paths 指定で注入範囲を絞り、無関係な作業へのノイズを避ける。

上書き契約 委譲可（値のみ）・一律適用・上書き禁止をruleごとに宣言する — プロジェクト側の変更はこの契約を越えない 2 / 3
Claude Code 設定管理 — プロジェクト規約

プロジェクト規約は固有ルールと委譲値を分ける

独自ruleと、globalから委譲された値の受け口を分離する

プロジェクト固有<repo>/.claude/rules/リポジトリ単位の規約と値の追加
always/プロジェクト内で常時注入
├─project-context/rule.md概要・技術スタック
├─naming-values.txt委譲受け口
├─prh.yml委譲受け口
└─domain/dictionary/ドメイン用語辞書

置くもの：リポジトリ内で常時必要な文脈と、globalから委譲された値の受け口（naming-values.txt / prh.yml）。独自 rule とは混ぜない。

scoped/対象パス操作時のみ注入
├─flow/approved-sha/マージ時のみ
├─project/context-scope/コード編集時
└─review-checklist/レビュー観点の追加

置くもの：このリポジトリ固有の条件付き規約。マージ時・コード編集時・レビュー時など、発動条件を明示して絞る。

受け口の分離 独自ruleと委譲値の受け口を分ける — 委譲はglobal契約が許す値だけ。hookと違反時手順は大元を確認する 3 / 3
