CLAUDE CODE 設定管理

規約は「所有レベル」×「注入タイミング」で整理する

グローバル／プロジェクト固有と、always／scopedを混ぜずに二段階で分類する

グローバル全プロジェクト共通
~/agent-home/rules/
プロジェクト固有リポジトリ単位
<repo>/.claude/rules/

global × always

全セッションへ常時注入する共通規約。命名・語彙・委任・応答などを置く。

global × scoped

対象パスの操作時だけ注入する共通規約。コード・開発フロー・hook設定などを置く。

project × always

そのリポジトリ内で常時必要な文脈と、globalから委譲された値を置く。

project × scoped

そのリポジトリ固有の条件付き規約。マージ時・コード編集時・レビュー時などに絞る。

第1軸:

所有レベル — 共通か、リポジトリ固有か

第2軸:

注入タイミング — 常時か、対象条件付きか

GLOBAL RULES

グローバル規約は共通原則と対象別基準を分ける

alwaysは全セッション、scopedは対象パス操作時だけ読み込み、上書き可否はruleごとに宣言する

グローバル ~/agent-home/rules/ — 全プロジェクト共通の規約
always/全セッションで常時注入
├─ naming/commit-branch/ 命名規約 hook 同居
├─ review-checklist/text-dictionary/ 語彙辞書
├─ agent/subagent-selection/ 委任規約 hook 同居
└─ response/ 応答規約の代表例
scoped/対象パス操作時のみ注入
├─ review-checklist/code/ paths: **/*.ts
├─ dev-flow/gate/ paths: src/**
└─ agent-config/hooks/ paths: tools/hooks/**
ruleごとの上書き契約

委譲可（値のみ）・一律適用・上書き禁止を各ruleの宣言で確認する。プロジェクト側が変更できる範囲は、この契約を越えない。

PROJECT RULES

プロジェクト規約は固有ルールと委譲値を分ける

独自ruleとglobalから委譲された値の受け口を分離し、hookと違反時手順は正本を確認する

プロジェクト固有 <repo>/.claude/rules/ — リポジトリ単位の規約と値の追加
always/プロジェクト内で常時注入
├─ project-context/rule.md 概要・技術スタック
├─ naming-values.txt 委譲受け口
├─ prh.yml 委譲受け口
└─ domain/dictionary/ ドメイン用語辞書
scoped/対象パス操作時のみ注入
├─ flow/approved-sha/ マージ時のみ
├─ project/context-scope/ コード編集時
└─ review-checklist/ レビュー観点の追加
✕ hook と違反時手順は正本を確認する。プロジェクト独自 rule と、global から委譲された値の受け口を分ける
独自rule:

プロジェクト文脈・条件付きフロー・追加レビュー観点

委譲値:

命名値・語彙辞書など、global契約が許す値だけ
