advisor tool — 上位モデルを相談役として常駐させる

設定は /advisor opus の1行。相談時は会話全文が渡り、前提を書き直さない

OPUS 5アドバイザー
方針を決める前 進め方の見立てを取る
失敗が続く時 別の見方を得る
完了の宣言前 見落としを検める
SONNET 5メイン
着手 範囲を読む
実装と修正 検査が通るまで
差分の整理 完了条件と照合
完了 検証を経て提示

上の3つは相談が入りやすい場面の例で、規則で定まった発火条件ではない。時機はモデルが決める。

設定で回数を増やすことも抑えることもできない。「advisor に批判的なレビューを受けてから提示して」のように、指示文で頻度や場面を調整する。

設定 /advisor opus　解除は /advisor off 選べる階層 相談先はメインと同等以上に限る。メインが claude-sonnet-5 なら Fable・Opus 5・Sonnet 5 が選べる
